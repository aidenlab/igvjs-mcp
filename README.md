# igvjs-mcp

An early-stage project from the [Aiden Lab](https://github.com/aidenlab). The repository currently holds an empty [Vite](https://vite.dev) + TypeScript scaffold; there is no application code yet.

## Requirements

- [Node.js](https://nodejs.org) and npm

## Getting started

```sh
npm install
npm run dev
```

`npm run dev` starts the Vite dev server and prints the local URL to open.

## Scripts

| Command           | What it does                                           |
| ----------------- | ------------------------------------------------------ |
| `npm run dev`     | Start the Vite dev server with hot module reload       |
| `npm run build`   | Type-check with `tsc`, then build for production into `dist/` |
| `npm run preview` | Serve the production build locally                     |

## Project layout

```
index.html      Page entry point; mounts #app and loads src/main.ts
src/main.ts     TypeScript entry point
src/style.css   Global styles
tsconfig.json   TypeScript configuration
```
