A Room’s addresses

A Room is the live channel on the Worker that joins the Connector to its Viewer. Its id is ten letters and digits, and the Worker accepts it in either case. Press New Room to open one on the chosen Deployment, the way open_viewer does, or paste an id from a Join card or from geenee.

AddressWhat it showsWho uses it
The Join link. The Viewer joins the Room and shows igv with its Controls strip, the Shareable URL included. The Join card’s button, and the model, which opens it beside the conversation.
The same Viewer, Embedded: no Controls strip. geenee’s Workspace, which frames it.
Not a page: the WebSocket the Viewer opens to its Room. A page from any origin but the Viewer’s is refused with 403, a malformed id with 400. The Viewer, for as long as it is open.

A Room expires after a day with no Viewer connected and no message; while a Viewer is connected it stays open. A Viewer that joins an expired Room says “This igv-bot has expired” and igv never starts. Nothing refuses an id the Worker has never seen: it is simply a new, empty Room. open_viewer with room renews an expired one.

Addresses that need no Room

AddressAnswerWhat it shows
200 What this Deployment runs: the Worker’s tag or branch and commit, and the Viewer’s, read from its version.json. A page in a browser, JSON to curl.
200 The Viewer’s own version, the one /version reads.
200 The Viewer in no Room. It opens no WebSocket.
405 The Connector address. Hosts POST to it; a browser’s GET is refused.
404 The Worker serves nothing else. The Viewer lives on its own host.

From the terminal

Each command uses the Deployment and Room chosen above. /mcp needs no sign-in and no session: one POST is one call, and room names the Room.

Open a Room



Prints the Join link, with the new Room id in it. This is what New Room does.



Open a Room at a gene




The same, but the Room starts on hg38 at MYC. room cannot be given with genome or locus.



Drive the Viewer




With the Join link open, igv goes to SOX2. Any tool from the list below works the same way, with the Room id as room. With no Viewer in the Room, the reply says so.



Ask about a Room




What the Viewer shows: genome, locus and tracks. An error until the Join link is open; geenee uses this to mark igv’s tab as connected.

Tricks worth knowing


    
  
  • geenee’s Room id works here. geenee opens its own Room id in igv’s Worker, so an id from a geenee Card drives the same igv that geenee’s Workspace frames.
    • 
  
  • Keep a Room alive by leaving its Join link open: while a Viewer is connected, the Worker does not expire the Room.
    • 
  
  • The MCP session id is a Room id. On initialize the Worker answers with a new Room id in mcp-session-id, and a Host that sends it back is tied to that Room. A room argument wins over it.
    • 
  
  • ChatGPT sends no session id. Its x-openai-session header is turned into a Room id instead.
    • 
  
  • Local development runs the Worker on localhost:8787 (npm run dev:server) and the Viewer on localhost:5173 (npm run dev:viewer), which passes /ws through to the Worker. Secrets go in server/.dev.vars.
